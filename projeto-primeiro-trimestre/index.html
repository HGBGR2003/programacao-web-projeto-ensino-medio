Sobre o Projeto

Este projeto foi desenvolvido como atividade avaliativa da disciplina de Programação Web no IF Goiano durante o Ensino Médio Integrado.

O objetivo central é consolidar os fundamentos da arquitetura web cliente-servidor: estruturação com HTML5 semântico, estilização moderna com CSS3 avançado (variáveis, temas e grid responsivo), interatividade com JavaScript ES6+ e integração completa com Servlets Java (Jakarta EE).

HTML5 CSS3 Variables JavaScript ES6+ Jakarta Servlets Dark/Light Mode 100% Responsivo
4 Formatos de Mídia
2 Temas (Dark / Light)
100% Sem Dependências Pesadas
10+ Melhorias Implementadas
